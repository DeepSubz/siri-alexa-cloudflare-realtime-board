The source of truth

One Markdown file, four stored keys

Everything the wall shows comes from tasks.md. People, Siri, Alexa and Muse all edit the same text; the board only reads it. Voice edits change one line and leave every other byte as it was.


      

        
Durable Object “Board” · SQLite storage

        

          
tasksThe whole Markdown file. Up to 256 KB.

          
updatedAtMilliseconds timestamp of the last save.

          
historyLast 8 voice changes. Used for 6 hours, so “undo” and “the last one” work.

          
pendingThe follow-up question just asked. Kept 3 minutes.

        

        
There is exactly one object, named family. Every write runs inside it, so a Siri edit and a Muse upload can never collide. The same object holds every open board’s WebSocket and pushes the file to them after each save.

        
How the board reads it

        
## Group starts a colour. - [ ] is a task, - [x] is crossed out, a plain line is a note and <!-- --> is hidden. Dates like “Thu Dec 3” or “due Dec 9” drive the TODAY and OVERDUE stamps.
