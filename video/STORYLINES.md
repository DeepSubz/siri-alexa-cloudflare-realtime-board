# Storylines

Built: **A — One sentence, end to end.** Chosen because a stranger follows a real moment (a sentence spoken in a kitchen) and every system enters as the thing that answers "how did that get on the wall?".

## A. One sentence, end to end (built)
Device: the worked example. Form: a flight through one isometric world, diving into each part, cut with simulated device demos.
First 2 s: the living-room TV board, a new post-it line being written by an invisible hand.
Beats: hook (kitchen → wall) → the world assembles → the file → Siri demo → request → AI → guards → Durable Object → push → TV → reply → Alexa demo → signature checks → crossed out everywhere → Muse at dawn → safety net → clocks → living wall → the whole machine → end line.
Look: drafting-paper map world (#e7ebf0) with the system's own colours; real-feeling rooms for the devices.
Sound: Qwen3-TTS narrator plus character voices, Pixabay beds per act, whooshes on camera dives, pops on landings.

## B. The clockwork (not built)
The whole system as a brass clock movement: each service a gear, each timer a hand; the camera opens the case and follows one tick.

## C. A day in the house (not built)
One day from 6:30 am to midnight in one continuous take across the house, each event (Muse at dawn, Siri at breakfast, Alexa after school, the midnight repaint) triggering its path.
